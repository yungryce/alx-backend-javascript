# Skills Index – Backend JavaScript

This document catalogs the comprehensive set of skills and competencies developed throughout the ALX Backend JavaScript curriculum.

## JavaScript Fundamentals

### ES6+ Syntax & Features
- **Variable Declarations**: let, const, block scoping
- **Arrow Functions**: Concise function expressions
- **Template Literals**: String interpolation and multi-line strings
- **Destructuring**: Arrays and objects
- **Spread/Rest Operators**: Flexible function arguments and array/object manipulation
- **Modules**: Import/export syntax for modular code

### Object-Oriented Programming
- **Classes & Inheritance**: ES6 class syntax, constructors, super, extends
- **Encapsulation**: Private/protected properties (conventions)
- **Static Methods**: Utility functions on classes
- **Instance Methods**: Behavior attached to objects

### Functional Programming
- **Array Methods**: map, filter, reduce, forEach, find, some, every
- **Immutability**: Avoiding side effects, using spread/rest
- **Higher-Order Functions**: Functions as arguments/return values

## Asynchronous Programming

### Promises & Async/Await
- **Promise Creation & Chaining**: then, catch, finally
- **Error Handling**: try/catch with async functions
- **Parallel & Sequential Execution**: Promise.all, Promise.race
- **Callback Patterns**: Legacy async code

## TypeScript
- **Type Annotations**: Static typing for variables and functions
- **Interfaces & Types**: Defining object shapes
- **Generics**: Type-safe reusable components
- **Type Inference**: Letting the compiler infer types

## Node.js & Backend Scripting

### Node.js Core
- **File System Operations**: Reading/writing files with fs
- **Modules**: CommonJS require/exports, ES modules
- **Process Management**: Accessing process info, environment variables
- **Event Loop**: Understanding async execution in Node.js

### Backend Patterns
- **API Endpoints**: Creating HTTP servers and endpoints
- **Error Handling**: Graceful error management in backend code
- **Testing**: Writing and running unit tests (Jest, assert)

## Skill Progression

This curriculum builds skills incrementally, with each project expanding on previous knowledge:

1. **Foundation**: ES6 syntax, variables, functions, and modules (0x00)
2. **Asynchronous Programming**: Promises, async/await, error handling (0x01)
3. **Object-Oriented Programming**: Classes, inheritance, encapsulation (0x02)
4. **Data Manipulation**: Array methods, functional programming (0x03)
5. **Type Safety**: TypeScript basics, interfaces, generics (0x04)
6. **Backend Scripting**: Node.js modules, file system, process management (0x05)

Each project introduces new concepts while reinforcing previously learned skills, creating a comprehensive foundation in backend JavaScript engineering.
